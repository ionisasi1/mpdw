2. Fungsi Bantu Perhitungan Akurasi

calc_accuracy <- function(actual, fitted) {
  
  n <- min(length(actual), length(fitted))
  actual <- actual[1:n]
  fitted <- fitted[1:n]

  error <- actual - fitted
  valid <- !is.na(error) & !is.na(actual) & actual != 0

  sse  <- sum(error[valid]^2)
  mse  <- mean(error[valid]^2)
  rmse <- sqrt(mse)
  mape <- mean(abs(error[valid] / actual[valid])) * 100

  data.frame(SSE = sse, MSE = mse, RMSE = rmse, MAPE = mape)
}

Berdasarkan nilai RMSE dan MAPE terkecil, metode SMA (n=3) memberikan hasil pemulusan paling akurat untuk data anomali suhu global ini. Hal ini mengindikasikan bahwa data tidak memiliki pola tren dan musiman yang kuat, sehingga metode sederhana seperti SMA sudah cukup menangkap pola data tanpa perlu komponen tren (DES) maupun musiman (Holt-Winters) yang justru menambah kompleksitas tanpa meningkatkan akurasi.
